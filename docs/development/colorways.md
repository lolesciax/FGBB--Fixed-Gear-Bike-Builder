# Colorway implementation review · 28 October 2026

## Audit and scope

Baseline `4185052`. The new [brief](../requirements/colorways.md) extends the completed geometry correction. The user confirmed no licensed graphics are supplied and authorized documented paint approximations with missing graphics flagged. Keep geometry, six canonical selections, backend policy and local-only development intact.

At the audit baseline, variants held a single HEX swatch plus a finish string; the 39 GLBs identified size geometry. Runtime paint overwrote every paint material with the same color/roughness; forks were separate dark materials. SVG used a global frame gradient and metallic fork. There was no versioned colorway record, region definition, finish-specific physical material or colorway publication gate. Product snapshots existed, but current-catalog merging could override a saved variant's appearance. The implementation below extends those existing systems.

The implementation will embed versioned model-specific colorways and exact size associations in existing Product records. Variant IDs remain the canonical selection. Materials and SVG regions will share definitions; same-size finishes will reuse geometry. Publication must validate source, scope, regions, assets and permissions. Referenced appearance revisions must remain immutable, including exports/garage/share previews. No custom paint editor or new component slots.

## Implemented behavior

- Embedded colorways extend the existing Product documents; the canonical configuration still stores the same six variant IDs. Each definition has exact model/revision and sizes, dated source/listing status, HEX and physical properties, region stops, permitted graphics, rights and missing-graphics disclosures. Sixteen published colorways add 68 finish-specific size variants. Four draft model records add four draft colorways and 17 draft variants; they remain unavailable. Every pre-existing variant ID and technical specification is retained.
- Cinelli includes the three sourced finishes; Dosnoventa has six finishes across LA/DET/BCN; Magnum and Ranger have two each. State, 8bar and Wabi retain one previously documented finish each. Unknown model years stay unspecified. Draft Tsunami, Engine11, Leader and Vigorelli Steel records do not become selectable through paint metadata.
- Original paint regions cover top/down/seat/head tubes, both stay pairs, fork blades, crown and bottom bracket. SVG uses geometry-aligned masks and gradients, including the shared thumbnail renderer. Three.js uses physical materials and bounded shader stops in the same tube coordinates. Gloss/matte/satin/metallic/clearcoat properties are supported as display approximations. Structural headsets, dropouts, steerer and other components retain their own materials.
- Identical size geometry keeps mesh/material objects and cached GLBs while uniforms and finish properties change. Existing 39 GLBs are reused. DET Falcon L uses its sourced 590mm seat tube through the procedural renderer instead of aliasing the 580mm Jet Black L kit. LA Traffic White retains its separate 28mm fork clearance without changing the old variant.
- Confirmed safe SVG path data and approved PNG/JPEG/WebP layers can be placed along model-relative tube regions. The 3D projector intersects the actual mesh, reverses the back-side reading axis, preserves artwork aspect and disposes owned decals/textures. A bounded canvas texture is created from prepared content; raw SVG uploads, remote executable markup and arbitrary texture URLs remain rejected. No manufacturer artwork is registered. Missing rasters retain paint and show a 3D accuracy warning.
- The existing private inbox now records hashes and audited admin approval notes. Only reviewed model-associated rasters referenced by published colorways are publicly served. Saved archived appearances remain accessible to their owner or through an existing public share; private snapshot images use private/no-store responses. Production use fails closed until a durable asset store is configured. No store was provisioned.
- The selector uses rendered frame/fork thumbnails, exact current-size variant lookup, pressed/disabled states and source/limitations feedback. Existing native variant controls remain available. Admins can stage drafts, next revisions, size associations, physical properties, region and graphics data, inspect 2D/3D previews and publish/archive through existing validation. Referenced variants and appearance definitions cannot be rewritten; create a new revision. Archiving remains available.
- Saved snapshots pin appearance across reopening, garage/share previews, updates and duplication. The shared SVG export embeds only the selected frame's approved raster bytes, avoiding cross-model graphic-ID collisions and external image dependencies. New selections exclude archived colorways. Authentication, ownership, CSRF, compatibility, editor revisions and backend policy remain enforced; the private local development quota bypass stays enabled.
