# Original studio presentation images

`studio-dark.png` and `studio-light.png` are local browser captures of TrackLab's independent procedural Studio Track assembly, using the same renderer and original softbox lighting as the builder. They are presentation illustrations, not manufacturer photos, licensed CAD, exact manufacturing geometry or user-saved builds.

The live headline, navigation, captions, environment switch and calls to action are HTML. No interface controls, manufacturer graphics or external HDR media are baked into these images. The selected-part shading visible in the capture is a studio interaction cue, not a claim about a manufacturer finish. Interactive 3D loads only after entering the builder and selecting 3D.
